# SAM and SAM 2 (Segment Anything Model)

This file covers both **SAM** (the original 2023 model) and **SAM 2** (the 2024 video-capable successor). Both are from Meta AI and both are inference-only in the Ultralytics package.

## SAM (v1)

### Overview
- **Release year:** April 2023.
- **Authors:** Meta AI (Alexander Kirillov et al.).
- **Description:** Promptable image segmentation. Takes an image plus a prompt (points, boxes, or a coarse mask) and returns precise segmentation masks. Trained on SA-1B (1B+ masks, 11M images).
- **Status:** Foundational. SAM 2 supersedes it for most uses.
- **License:** Apache-2.0.

### Tasks supported
- [x] segment (promptable; not class-aware)
- All other YOLO tasks: not applicable.

### Variants

| Variant | Filename     | Params (M) | Encoder | Size on disk | Dataset |
|---------|--------------|-----------:|---------|-------------:|---------|
| Base    | `sam_b.pt`   | 93.7       | ViT-B   | 375 MB       | SA-1B   |
| Large   | `sam_l.pt`   | 312        | ViT-L   | ~1.2 GB      | SA-1B   |
| Huge    | `sam_h.pt`   | 641        | ViT-H   | ~2.4 GB      | SA-1B   |

(Ultralytics' page primarily highlights `sam_b` and `sam_l`; `sam_h` is loadable.)

### Filename convention
- `sam_<size>.pt` where `<size>` ∈ {b, l, h}.
- Underscore, not hyphen.
- No size letters n/s/m/x.

## SAM 2

### Overview
- **Release year:** July 2024.
- **Authors:** Meta AI (Nikhila Ravi et al.).
- **Description:** Promptable segmentation for both **images and video**. Adds a memory mechanism for temporal coherence and ~44 FPS real-time inference. Trained on SA-V (51K+ videos, 600K+ masklets).
- **Status:** Current. Pick over SAM v1 for any new use.
- **License:** Apache-2.0.

### Variants

| Variant       | Filename          | Params (M) | Notes |
|---------------|-------------------|-----------:|-------|
| Tiny          | `sam2_t.pt`       | ~39        | Fastest |
| Small         | `sam2_s.pt`       | ~46        | |
| Base+         | `sam2_b.pt`       | ~80        | |
| Large         | `sam2_l.pt`       | ~224       | Most accurate |
| SAM 2.1 tiny  | `sam2.1_t.pt`     | —          | Updated weights |
| SAM 2.1 small | `sam2.1_s.pt`     | —          | |
| SAM 2.1 base+ | `sam2.1_b.pt`     | —          | |
| SAM 2.1 large | `sam2.1_l.pt`     | —          | |

### Filename convention
- SAM 2: `sam2_<size>.pt`, `<size>` ∈ {t, s, b, l}.
- SAM 2.1: `sam2.1_<size>.pt`.

### Pretrained datasets
- SA-1B (SAM v1) — 1B+ masks over 11M images.
- SA-V (SAM 2) — 51K+ videos, 600K+ masklets.

## Features / Notable capabilities (both)
- **Promptable** — point, box, or mask prompt.
- **Zero-shot** — no fine-tuning required for new domains.
- **Class-agnostic** — outputs masks, not class IDs.
- **SAM 2 only:** video segmentation with memory across frames, ~44 FPS.
- Bounding-box prompts can be auto-generated by chaining a YOLO detector → SAM mask refinement.

## Predict-time args worth surfacing in UI
- `points`: list of `[x, y]` foreground/background hints.
- `bboxes`: list of `[x1, y1, x2, y2]` prompt boxes.
- `labels`: per-point 0 (background) or 1 (foreground).
- `texts` (SAM 2 only, some configs): text prompts.
- `imgsz`, `device`, `half`, standard.

## Train-time args worth surfacing in UI
- **Not supported** in `ultralytics`. SAM and SAM 2 are inference-only.

## Quirks / Gotchas
- Use `from ultralytics import SAM` (both v1 and v2 share the class).
- Output is masks only — pair with a detector if you need class labels.
- SAM v1 base model is already 375 MB; budget storage accordingly.
- Image encoder dominates latency. For real-time, use FastSAM or MobileSAM.
